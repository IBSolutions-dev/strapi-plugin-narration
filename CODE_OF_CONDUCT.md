# Code of Conduct

Be respectful. Harassment, personal attacks, and discrimination are not
welcome — in issues, pull requests, commit messages, or any other repository
interaction.

## Reporting

If someone is violating this in a repository interaction, open an issue at
[github.com/IBSolutions-dev/strapi-plugin-narration/issues](https://github.com/IBSolutions-dev/strapi-plugin-narration/issues)
describing the behavior, or contact the maintainer
[@ivarsbariss](https://github.com/ivarsbariss) directly through GitHub.
**Do not** use GitHub Security Advisories — those are for security
vulnerabilities and are routed in [`SECURITY.md`](./SECURITY.md).

The maintainer will review reports privately and may remove offending
content, restrict the offender's repository access, or escalate to GitHub
abuse reporting as appropriate.
