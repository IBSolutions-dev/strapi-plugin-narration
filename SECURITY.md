# Security Policy

## Supported versions

The latest `1.x` release line is supported.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Use GitHub **Security Advisories**:

- Go to the repository → **Security** → **Advisories** → **Report a vulnerability**.

Include:

- Strapi version, Node version, and plugin version
- Steps to reproduce
- Impact assessment (what an attacker can do)
- Any relevant logs (do **not** include secrets)

## Response

Security reports are reviewed privately.

- **Acknowledgement**: within **7 days** of the advisory being filed.
- **Initial assessment / triage**: within **14 days** of acknowledgement.
- **Fix or mitigation**: targeted within **90 days** of triage; complex issues
  may take longer with a status update on the advisory.

If a fix is needed, it will be released as a patched npm version and
documented in `CHANGELOG.md`. Credit will be given in the advisory unless the
reporter requests otherwise.
